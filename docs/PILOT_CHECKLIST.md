# SENTRY Design-Partner Pilot Checklist

Use this for each of the first 3 SMB design partners (2-week guided onboarding).

## Before kickoff
- [ ] Confirm champion (founder / office manager) and 1–2 power users
- [ ] Agree success questions (5–10 real questions they ask weekly)
- [ ] Collect initial sources: policies, SOPs, vendor list, invoice/expense CSV export
- [ ] Create their workspace in SENTRY
- [ ] Schedule kickoff (45 min) + mid-week check-in + wrap (30 min)

## Kickoff (Day 1)
- [ ] Walk through SENTRY brand promise: answers from *their* data with sources
- [ ] Upload initial docs together (aim for useful answer in first session)
- [ ] Run 3 success questions live; verify citations look right
- [ ] Show source admin (add / delete / status)
- [ ] Leave them with login + 5 starter prompts tailored to their business

## Week 1
- [ ] Champion asks ≥5 real questions in-product
- [ ] Note misses: wrong answer, missing source, hallucinated fact
- [ ] Add missing docs when “I don’t know” is correct
- [ ] Spot-check tenancy: no leakage from demo or other workspaces

## Week 2
- [ ] Expand sources (books CSV, onboarding SOP, customer FAQ)
- [ ] Invite second user if ready
- [ ] Capture a quote for the site (optional)
- [ ] Measure: active askers, “used without re-check” rate, time-to-first-useful-answer

## Wrap
- [ ] Review wins and gaps against success questions
- [ ] Decide: continue paid Starter / pause / expand sources
- [ ] Log feature requests (connectors, permissions, actions)
- [ ] Send thank-you + next steps
