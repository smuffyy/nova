# SENTRY — Company One-Pager

## What it is
SENTRY is how a company becomes knowable — the watcher over company memory — four surfaces on one grounded memory:

1. **Chat** — institutional truth: how you operate, unique methods, standards (billing, IT, logistics…)
2. **Sidekick** — each person’s LLM companion: doubts, cross-domain learning, scheduling, collaboration
3. **Agents** — named specialists that do domain work (Moony, Path, Compu, Ledger, Quill, Relay)
4. **Digest** — the week’s pulse: news, email summary, meetings, how things landed

## Positioning
- **Category:** Private company operating system for knowledge + action (not generic ChatGPT)
- **Promise:** New hires inherit how you work; everyone gets a Sidekick; specialists run inside your standards; the week is visible
- **Trust:** Never invent company facts — cite or refuse; agents propose, humans approve write-backs

## ICP (first customers)
5–50 person SMBs (agencies, professional services, light e‑commerce) where onboarding, standards, and “where is that?” still live in people’s heads and inboxes.

## Product thesis
| Surface | Job |
|---------|-----|
| Chat | Company memory & standards studio |
| Sidekick | Personal friend + cross-domain learner; can meet other Sidekicks |
| Agents | Moony (billing), Path (shipping), Compu (IT), Ledger (books), Quill (standards), Relay (handoffs) |
| Digest | Default morning home — news, mail, meetings, week |

## Offer / pricing
| Tier | Who | Price |
|------|-----|-------|
| Pilot | 3–5 design partners | Free or fixed fee, 2 weeks guided onboarding |
| Starter | Single workspace teams | Flat workspace + N seats (set at pilot close) |
| Connectors (later) | Growing teams | Drive, mail, calendar, books packs |

## MVP scope
- Multi-tenant workspaces
- Chat over uploaded policies/SOPs/exports with citations
- Sidekick thread per user (personal context + company Chat)
- Agent stubs: Moony / Path / Compu (read + draft; no silent write-back)
- Digest: meetings + uploaded “week notes” / email summary placeholder
- Demo workspace for marketing / pilots

## Out of scope (v1)
- Autonomous write-backs without approval
- Full multi-agent rooms (Sidekick combine) — design for it, ship later
- Live QuickBooks/Xero sync (CSV export is the bridge)

## Roadmap
1. **Now:** Brand, site, grounded Chat
2. **Next:** Sidekick + Digest (calendar/mail summary)
3. **Then:** Moony / Path / Compu actions with human approval
4. **Later:** Quill standards publish flow, Relay handoffs, Sidekick rooms

## Design-partner motion
- Recruit 3 SMBs you know
- **Success metrics:** time-to-first useful answer for a new hire · weekly Digest opens · agent drafts accepted without full rewrite

## Core principles
- Never invent company facts — cite or say unknown
- Chat = shared; Sidekick = personal; clear walls with intentional meetups
- Agents act inside published standards
- Hard tenancy isolation on every query
